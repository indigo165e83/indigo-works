## My Works

### 🖼️ <a href="https://free-images.indigo165e83.com/ja" target="_blank" rel="noopener noreferrer">Free Images</a>

AIで生成した画像をストックし、フリーで提供するWebサイトです。

開発記録は[こちらのブログ記事](/blog/20260201-free-images-dev-log/)をご覧ください。

**GitHub**: [indigo165e83/free-images](https://github.com/indigo165e83/free-images)

* **Tech Stack**
  - **Framework**: Next.js 16 (App Router)
  - **Language**: TypeScript
  - **Styling**: Tailwind CSS
  - **Database**: PostgreSQL (Neon) / Prisma
  - **AI Model**: Google Gemini (`nano-banana-pro-preview`, `gemini-2.5-flash`)
  - **Storage**: AWS S3
  - **Auth**: NextAuth.js (v5)
  - **Infrastructure**: Vercel
