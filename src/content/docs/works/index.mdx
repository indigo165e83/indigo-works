### <Briefcase size={28} style={{color: '#8b5cf6', display: 'inline-block', verticalAlign: 'middle', marginRight: '0.4rem'}} /> ニュースコンテンツ配信プラットフォームの品質保証・運用

**担当フェーズ**: APIテスト / 不具合解析 / ソースコード修正 / テスト設計・実施 / CI/CD運用

**担当業務**:

- **Python製DAGの運用・バグ修正**  
  Apache Airflow（Cloud Composer）上の月次収益計算パイプラインを担当。バリデーションエラー発生時にソースコードレベルで原因を特定し、Pythonコードのバグ修正を実施
- **BigQuery / SQL によるデータ品質検証**  
  日米間の収益按分・手数料など複雑な計算ロジックの妥当性を、SQLで期待値を算出して実システム出力と突合
- **CI/CD パイプライン運用・リリース管理**  
  GitHub Actions を用いたテスト実行パイプラインを運用し、Dev / Prod 環境へのデプロイをリリース前テストから本番反映まで一貫して管理
- **生成AI（LLM）出力の品質評価プロセス設計**  
  GPT-4o / Gemini を用いたスライドショー自動生成機能のQAプロセスを構築。評価基準の策定、不具合傾向の分析、開発チームへのフィードバックサイクルを確立
- **障害対応・DB レベルのデータリカバリ**  
  GCP Datastore のレコード修正・再計算ジョブの再実行など、システム内部に踏み込んだ障害対応を実施
- **グローバルチームとの仕様調整**  
  PM・日米ビジネスチーム・海外エンジニア（ベトナム / インド）と英語・日本語で連携し、仕様書・運用マニュアルを継続的に整備

**使用技術**: Python / SQL / GCP（BigQuery / Cloud Storage / Datastore / Cloud Composer）/ Apache Airflow / GitHub Actions / OpenAI GPT-4o / Google Gemini
