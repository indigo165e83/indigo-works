## My Works

### 🖼️ Free Images

AIで生成した画像をストックし、フリーで提供するWebサイトです。

開発記録は[こちらのブログ記事](https://indigo165e83.com/blog/20260201_free-images-dev-log/)をご覧ください。

**URL**: [サイトを見る](https://free-images.indigo165e83.com)
* **Framework**: Next.js 16 (App Router)
* **Language**: TypeScript
* **Database**: PostgreSQL (Neon) / Prisma
* **AI Model**: Google Gemini (`nano-banana-pro-preview`, `gemini-2.5-flash`)
* **Storage**: AWS S3
* **Auth**: NextAuth.js (v5)

### 📊 Next.js Dashboard
**財務管理ダッシュボード（Next.js公式チュートリアル拡張）**

Next.js公式サイトの学習コースをベースに構築した、フルスタックな財務ダッシュボードアプリケーションです。

* **URL**: [サイトを見る](https://nextjs-dashboard.indigo165e83.com/)
* **主な機能**:
    * 公開ホームページ（LP）
    * ログイン認証機能
    * 認証保護されたダッシュボード画面
    * 請求書（Invoice）のCRUD操作（追加・編集・削除）
