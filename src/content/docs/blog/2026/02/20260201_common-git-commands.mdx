gitのよく使うコマンドのメモ。<br />
直前のコミットに修正を追加する方法<br />

## まだ Push していない場合
コミットが自分のPC内（ローカル）だけにしかない場合

1.漏れていた修正を行い、保存する。

2.修正したファイルをステージング（add）する。

```Bash
git add .
```
2.直前のコミットに合流させる。

```Bash
git commit --amend --no-edit
```
- `--amend` : 直前のコミットをやり直す。

- `--no-edit` : コミットメッセージ（「〜を追加」など）を変更せずにそのまま使う。

## すでに Push してしまった場合（注意が必要）
GitHubなどのリモートサーバーに一度 Push してしまったコミットを修正する場合、「サーバー上の歴史を無理やり書き換える」 ことになります。

1.上記と同じ手順でローカルのコミットを修正する。<br />
`git add .` → `git commit --amend --no-edit`

2.強制的に Push（Force Push）する。

```Bash
git push -f origin [現在のブランチ名]
```

[!CAUTION]
チーム開発での注意点
共有ブランチ（main や develop など）でこれを行うと、他のメンバーの履歴と整合性が取れなくなり、混乱を招く可能性があります。
「自分一人で作業しているブランチ」 か、「PR（プルリクエスト）を出した直後で、まだ誰もレビューを始めていない」 状態の時にだけ行うのが安全です。
