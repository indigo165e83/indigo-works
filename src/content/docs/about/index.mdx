## プロフィール

名古屋を拠点に活動するフリーランスエンジニアです。<br />
モダンWebアプリ開発と良いテストに興味があります。<br />
QAエンジニア：5割、フロントエンド：3割、バックエンド開発：2割くらいの人です。<br />
組み込み系からWeb系へ移行しました。

## スキルセット

### テスト・品質保証
- **テスト自動化**: Playwright
- **資格**: JSTQB Foundation Level

### フロントエンド
- **フレームワーク**: Next.js, Astro, React
- **言語**: TypeScript, JavaScript
- **スタイリング**: Tailwind CSS

### バックエンド・インフラ
- **データベース**: PostgreSQL, BigQuery
- **ORM**: Prisma
- **クラウド**: Vercel, AWS (S3)
- **認証**: NextAuth.js (Auth.js)

## 当サイトについて

当サイト「Indigo Works」は、技術学習の記録やブログ記事を発信する個人サイトです。主に以下のコンテンツを提供しています。

- **Tech Blog**: Web開発に関する技術記事やトラブルシューティング
- **JSTQB学習ノート**: ソフトウェアテスト資格の学習まとめ
- **Essential Scrum**: スクラム開発の学習ノート
- **TypeScript入門**: TypeScriptの学習ノート
- **入門 Python 3**: Pythonの学習ノート
