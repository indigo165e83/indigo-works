## プロフィール

名古屋を拠点に活動するフリーランスエンジニアです。<br />
モダンWebアプリ開発と良いテストに興味があります。<br />

長年にわたるシステム開発・QAエンジニアリング経験を持ちます。<br />
エンジニアとしてのキャリアを組込み系（FA制御・自動車ECU）から始め、<br />
近年はWeb系領域（PC・モバイル・クラウド）を中心に、TypeScript/Python/SQLでの開発経験を活かしたコードベースのQA/品質保証業務を担っています。<br />

「コードが読めるQAエンジニア」としての強みを活かし、現在はテスト自動化エンジニア（SET）への
キャリアシフトを積極的に進めています。

## スキルセット

### QA / テスト（実務経験）

- **テスト設計・実施**: 要求仕様・設計書に基づくテスト分析、テスト仕様書作成、テスト実行
- **APIテスト**: Postman / Charles を用いたAPIテスト設計・実施
- **ホワイトボックステスト**: ソースコード・ログ・DBを直接検証する技術的なQA、不具合の根本原因特定
- **CI/CD連携**: GitHub Actions を用いたテスト実行パイプラインの運用（実務）
- **資格**: JSTQB Foundation Level 保有

### プログラミング（実務経験）

- **言語**: TypeScript / JavaScript、Python、SQL（DML/DDL）、C、アセンブラ
- **クラウド**: GCP（Cloud Composer / BigQuery / Datastore / GAE）、AWS
- **ツール**: Docker、Postman、Swagger、Charles、GitHub、VSCode

### テスト自動化（学習・習得進行中）

- **E2Eテスト**: Playwright（自己学習中 → [学習ノートはこちら](/test/playwright/overview/)）
- **資格**: JSTQB Advanced Level Test Analyst（取得に向け学習中 → [学習ノートはこちら](/jstqb/overview/)）

### フロントエンド・バックエンド（学習・個人開発）

- **フレームワーク**: Next.js、Astro、React
- **スタイリング**: Tailwind CSS
- **ORM**: Prisma
- **認証**: NextAuth.js（Auth.js）
- **公開サービス**:
  - [Free Images](https://free-images.indigo165e83.com/ja) — AI画像素材ストックサービス
  - [4Testing](https://4testing.indigo165e83.com/ja) — 開発者向けテストデータ生成ユーティリティ

## お仕事のご依頼

フリーランスエンジニアとして、以下のお仕事を受け付けています。

### 得意な領域（実績あり）

- **テスト設計・実施**: Webアプリ / API / モバイルアプリのテスト設計・実行
- **APIテスト**: Postman / Charles を使ったAPI品質検証
- **不具合解析**: ログ解析・DB検証を伴う根本原因の特定
- **CI/CDパイプライン運用**: GitHub Actions を使ったテスト・デプロイの自動化運用
- **技術記事の執筆**: QA・テスト自動化・Web開発に関する記事

### 積極的に挑戦したい領域

- **E2Eテスト自動化**: Playwright を用いたテスト基盤の構築
- **テスト自動化のCI/CD統合**: 自動テストの継続的実行パイプライン構築
- **テスト自動化導入支援**: 既存の手動テストから自動化への移行支援
