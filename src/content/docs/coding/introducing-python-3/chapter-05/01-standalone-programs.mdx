これまでは、Pythonの「対話型インタープリタ」を使って、短いコードの断片を書いてはすぐに実行結果を確認してきました。

```python
# 対話型インタープリタでの実行例
>>> print("This interactive snippet works.")
This interactive snippet works.
```

しかし、現実的で大規模なプログラムを書くためには、コードをファイルに保存して独立して動かせる**スタンドアローンプログラム**を作成する必要があります。

## 初めてのスタンドアローンプログラム

テキストエディタを開き、以下の1行だけのPythonコードを記述して、`test1.py` という名前のファイルとして保存します。

```python
# test1.py の内容
print("This standalone program works!")
```

<Aside type="caution" title="インデントに注意">
`print` の前にスペースやタブなどのインデント（字下げ）を入れないように注意してください。また、対話型インタープリタで表示されていた `>>>` のようなプロンプトは入力しません。
</Aside>

## プログラムの実行方法

テキストターミナル（またはコマンドプロンプトやターミナルウィンドウ）を開き、`python` コマンドの後に先ほど作成したファイル名を指定して実行します。

```bash
$ python test1.py
This standalone program works!
```

これで、ファイルに記述したコードが独立したプログラムとして実行されました。

<Aside type="tip" title="対話型コードをファイルに移すときの注意">
これまでの章で紹介されてきた対話型コードは、すべてファイルに保存すれば直接実行することができます。
ただし、本やウェブサイトからカット＆ペーストしてファイルに貼り付ける際は、**行の先頭にある `>>>` や `...` （およびその直後のスペース）を必ず削除**してください。
</Aside>
